# Vellum Design System

## Principles

Consistency over customization.

Composition over duplication.

Reusable over one-off.

---

## Core Components

- CommandCard
- RecommendationCard
- MetricCard
- StatusBadge
- SectionHeader
- EmptyState

---

## Layout

Pages compose components.

Components compose primitives.

Avoid repeated Tailwind class strings.

---

## Typography

Headers:

font-light

Body:

text-foreground/70

Labels:

text-sm uppercase tracking-wide

---

## Cards

Every dashboard card should begin with CommandCard unless a compelling reason exists otherwise.
